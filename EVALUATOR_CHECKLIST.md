# Чек-лист проверки

## Доказательность версии 2

- [ ] Таблица baseline → regret-2 рассчитывается на одинаковом наборе данных и показывает нулевые hard violations.
- [ ] В статусе матрицы указано `OSRM: дорожное время и расстояние`; при недоступности сети явно показан резервный режим.
- [ ] В плане заявки отображается причина выбора инженера и ближайшая совместимая альтернатива.
- [ ] Кнопка «Сценарий защиты» показывает цепочку «до → событие → после» и рассчитанные KPI.
- [ ] Статус заявки можно изменить на «не начата / в пути / начата / завершена» и указать фактическое время.
- [ ] Оперативное перепланирование сохраняет только фактически зафиксированные работы.
- [ ] Ручное назначение с неверным навыком, транспортом, окном или сменой блокируется.
- [ ] Временное наложение требует причины для журнала действий.
- [ ] Quality gate сообщает число принятых и отклонённых строк и причины отклонения.

- [ ] Главная страница открывается без ошибок.
- [ ] Карточка «Распределено» показывает математически верный процент.
- [ ] Кнопка «Настроить параметры смены» открывает загрузку заявок, XLSX инженеров, нормативы и автотриггер.
- [ ] Нормативы нельзя заменить; доступен стандартный файл `Нормативы.xlsx`.
- [ ] Кнопка «Рассчитать план» обновляет метрики и маршруты.
- [ ] Карточка «Инженеры в плане» открывает список сотрудников и графики.
- [ ] План инженера содержит все его заявки и кнопку ручного перепланирования.
- [ ] Точки на реальной карте открывают карточки заявок.
- [ ] Линии маршрутов проходят по дорогам; при недоступности OSRM показывается резервная прямая.
- [ ] Ручное наложение увеличивает показатель «Перегружено специалистов».
- [ ] «Новое событие» добавляет аварийную заявку и увеличивает счётчик новых заявок.
- [ ] «Новое событие» позволяет отметить инженера не на линии и перепланировать его заявки.
- [ ] Во вкладке статуса инженера нет полей заявки; снятого сотрудника можно вернуть на линию.
- [ ] В 08:00 запускается утреннее распределение, позднее — оперативное перепланирование.
- [ ] При оперативном перепланировании уже начатые заявки сохраняют инженера и время и помечаются как зафиксированные.
- [ ] «Свободный ресурс» отображается в часах и минутах, без десятичной дроби.
- [ ] Текущее время смены изменяется в настройках и отражается в шапке и матрицах.
- [ ] Карточки распределения, пробега, свободного ресурса и перегрузки открывают подробности.
- [ ] Фильтры «С риском» и «В резерве» одновременно изменяют список и карту.
- [ ] Ручное перепланирование показывает риски и изменения относительно оптимального плана.
- [ ] Для нераспределённой заявки недоступные инженеры показаны неактивными с причиной.
- [ ] Порог автопересчёта включается, выключается и принимает значение от 1 до 180 минут.
- [ ] На графике отображается накопленное отставание.
- [ ] Интерфейс остаётся читаемым на мобильной ширине.
