# Уральские самоцветы — планирование маршрутов инженеров

Веб-прототип для кейса «Билайн Бизнес»: распределение заявок по выездным инженерам, сравнение baseline с regret‑2, карта маршрутов и оперативное перепланирование по факту исполнения.

Этот репозиторий содержит **версию 2**: готовое статическое приложение в `dist/`. Расчёт выполняется в браузере на JavaScript. Для запуска достаточно HTTP-сервера; установка Node.js, npm-пакетов или Python-зависимостей приложения не требуется.

## Запуск за минуту

Скачайте репозиторий через **Code → Download ZIP** и распакуйте либо клонируйте:

```bash
git clone https://github.com/MyXadoter/ural_samocvet.git
cd ural_samocvet
```

В терминале из корня репозитория запустите:

```bash
# macOS / Linux
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

```powershell
# Windows
py -3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Терминал должен оставаться открытым; остановка — `Ctrl+C`. Требуется установленный Python 3. В Windows также доступен [start-local.cmd](start-local.cmd), который запускает сервер без ограничения интерфейса; подробности — в [инструкции запуска](docs/LOCAL_SETUP.md).

Для загрузки карты, дорожной матрицы и библиотеки чтения Excel нужен интернет. При ошибке OSRM расчёт переключается на географическую оценку и показывает источник данных над сравнением алгоритмов.

Опубликованная версия указана в [VERSION.md](VERSION.md). Её соответствие текущим файлам репозитория нужно проверять отдельно.

## Возможности

- Стартовый набор из 10 заявок и 6 инженеров, включая резервного сотрудника.
- Загрузка заявок из CSV, XLSX/XLS или JSON и инженеров из XLSX/XLS с отчётом об отклонённых строках.
- Утренний расчёт с ограничениями по навыку, транспорту, временному окну и смене.
- Сравнение количества назначений, инженеров, пробега, SLA и совместимости.
- План инженера, карта OpenStreetMap, статусы исполнения и фактическое время.
- Аварийная заявка, снятие инженера с линии, ручная корректировка и оперативный пересчёт.
- Встроенный «Сценарий защиты» с состояниями до и после события.

## Границы версии 2

Приложение остаётся демонстрационным прототипом. Координаты заявок вычисляются по району и ID, координаты импортированных инженеров — по номеру строки; адреса не геокодируются. OSRM строит автомобильные маршруты между этими учебными точками. Пробки и отдельная модель общественного транспорта не учитываются.

Состояние находится в памяти вкладки: обновление страницы сбрасывает загруженные данные, факты и изменения. Серверной БД, авторизации, постоянного журнала, собственного REST API и экспорта плана в этой версии нет.

Нулевой показатель `Hard constraints` отражает проверку совместимости, а не полную независимую проверку плана. После ручных изменений показатели расстояния могут быть неполными. Подробности — в [VALIDATION.md](docs/VALIDATION.md).
