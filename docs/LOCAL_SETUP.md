# Локальный запуск

[Документация](README.md) · [Руководство диспетчера](USER_GUIDE.md)

## Требования

- Современный браузер с поддержкой JavaScript, `fetch` и HTML `dialog`.
- Python 3 с модулем стандартной библиотеки `http.server` либо другой HTTP-сервер статических файлов.
- Интернет для библиотек Leaflet и SheetJS, тайлов OpenStreetMap и сервиса OSRM.

В репозитории уже есть исполняемые файлы в `dist/`. Команд установки пакетов и сборки нет. Python только раздаёт файлы; алгоритмы выполняются в браузере.

## Получение проекта

На [странице репозитория](https://github.com/MyXadoter/ural_samocvet) выберите **Code → Download ZIP**, распакуйте архив и откройте терминал в папке, содержащей `dist/`. При наличии Git:

```bash
git clone https://github.com/MyXadoter/ural_samocvet.git
cd ural_samocvet
```

## macOS и Linux

```bash
python3 --version
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Сервер работает, пока открыт терминал. Для остановки нажмите `Ctrl+C`.

## Windows

В PowerShell или командной строке:

```powershell
py -3 --version
py -3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Если установлен Python без команды `py`, используйте:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Остановка — `Ctrl+C`.

В корне также есть [start-local.cmd](../start-local.cmd): двойной щелчок запускает сервер и оставляет окно открытым. Скрипт сам переходит в папку проекта, пробует `py -3`, затем `python`. Браузер нужно открыть самостоятельно. Скрипт не задаёт `--bind 127.0.0.1`: сервер слушает доступные сетевые интерфейсы. Для запуска только на своём компьютере используйте явную команду с `--bind`.

## Первая проверка

1. Дождитесь появления плана: исходные данные — 10 заявок и 6 инженеров.
2. Посмотрите строку над сравнением алгоритмов: `OSRM: дорожное время и расстояние` либо `Резерв: географическая оценка`.
3. Откройте карточку инженера и проверьте список назначений.
4. Откройте «Настроить параметры смены»: там доступны импорт и скачивание нормативов.

Сразу после загрузки приложение рассчитывает план с географической оценкой. Затем пробует получить матрицу OSRM и рассчитывает его ещё раз. Поэтому начальные показатели могут измениться после сетевого ответа. Ожидание матрицы ограничено 9 секундами; ожидание геометрии отдельного маршрута — 7 секундами.

## Сеть и хранение

| Назначение | Адрес, используемый приложением |
|---|---|
| Leaflet 1.9.4 | `unpkg.com` |
| SheetJS/XLSX 0.18.5 | `cdn.jsdelivr.net` |
| Подложка карты | `tile.openstreetmap.org` |
| Матрица и линии маршрутов | `router.project-osrm.org` |

Собственный ключ API и `.env` не нужны. Выбранные файлы читаются в браузере, серверной загрузки CSV/XLSX в приложении нет. Во внешние запросы OSRM попадают координаты; запросы тайлов обозначают область карты.

Если OSRM недоступен, алгоритм работает с резервной оценкой. Полный автономный режим не реализован: без уже загруженной библиотеки Leaflet карта не появится, без SheetJS недоступен Excel-импорт. CSV/JSON не требуют SheetJS.

Состояние хранится только в текущей вкладке. Обновление страницы заново загружает демонстрационные данные. Остановка HTTP-сервера сама по себе не сохраняет план. Загрузка новых файлов также запускает новое утреннее планирование.

## Устранение ошибок

| Симптом | Действие |
|---|---|
| `python3`, `py` или `python` не найден | Установите Python 3 или используйте доступный статический HTTP-сервер |
| Порт занят | Запустите команду с портом `4174` и откройте `http://127.0.0.1:4174` |
| Список файлов или ошибка 404 | Проверьте рабочую папку и аргумент `--directory dist` |
| Страница открыта через `file://` | Откройте HTTP-адрес локального сервера |
| `Модуль XLSX ещё загружается` | Проверьте доступ к `cdn.jsdelivr.net`; повторите импорт после загрузки библиотеки |
| Карта пустая | Проверьте доступность Leaflet и тайлов, ошибки сети в инструментах браузера |
| Показан резервный режим | Дождитесь сети и нажмите «Рассчитать план» для повторного запроса матрицы |
| Файл отклонён | Сверьте поля и время с [форматами данных](DATA_FORMATS.md); сообщение содержит первую причину |
| Изменения исчезли после обновления | Это текущее поведение: постоянного сохранения нет |

## Изменение приложения

Правьте `dist/index.html`, `dist/app.js`, `dist/styles.css` и `dist/overrides.css`, затем обновляйте страницу. Конфигурации сборщика, `package.json` и серверного приложения в этом репозитории нет. При статическом размещении публикуется содержимое `dist/` с сохранением каталога `assets/`.
