# Форматы данных

[Документация](README.md) · [Руководство диспетчера](USER_GUIDE.md)

## Общие правила

Импорт находится в «Настроить параметры смены». Заявки принимаются из CSV, XLSX/XLS и JSON; инженеры — из XLSX/XLS. Каждый успешный импорт **заменяет** соответствующий набор и запускает утреннее планирование. Для частично корректного файла используются только принятые строки. Если все строки отклонены, прежние данные сохраняются.

В Excel выбирается первый лист, имя которого содержит `исход`, `заяв` или `инжен` без учёта регистра; если такого листа нет — первый лист книги. Поэтому для надёжного импорта размещайте одну таблицу на отдельном листе `Заявки` или `Инженеры`, с заголовками в первой строке.

CSV читается через `File.text()`: используйте UTF‑8, допустим BOM. Автоматического определения Windows‑1251 нет. Разделитель `;` либо `,` выбирается по первой строке. Парсер упрощён: избегайте многострочных ячеек и кавычек внутри значений. JSON должен содержать массив объектов и иметь расширение `.json` в нижнем регистре.

## Заявки

Пример из репозитория: [examples/requests.csv](../examples/requests.csv), 5 строк.

| Поле таблицы | Альтернатива JSON | Правило |
|---|---|---|
| `Заявка` | `ID` или `id` | Непустой уникальный ID; хранится строкой |
| `Тип заявки BK` | `bk` | Категория для приоритета, может быть пустой |
| `Тип заявки HD` | `type` | Непустой тип работ |
| `Начало` | `start` | Начало окна `HH:MM` |
| `Окончание` | `end` | Конец окна `HH:MM`, позже начала |
| `Район` | `zone` | Точное имя из поддерживаемого списка |
| `Адрес` | `address` | Непустой текст для отображения |
| `Навык` | `skill` | Если пусто, определяется по типу работ |
| `Транспорт` | `transport` | Пусто — без ограничения; иначе точное совпадение с транспортом инженера |
| `Длительность` | `duration` | Положительное число минут; при пустом значении — `normFor(type)` |
| `Гигабитное подключение` | `gigabit` | Значение, содержащее `Да`, включает признак; используйте строки `Да`/`Нет` |

Не передавайте JSON `true` для `gigabit`: нормализатор ищет текст `да`, а не логическое значение. Для ID используйте строки, особенно если значимы ведущие нули.

Время читается как последние пять символов значения. Подходят `09:00` и `17.08.2026 09:00`; дата при этом отбрасывается. Значения `9:00`, время с секундами и числовые Excel-даты не соответствуют этому контракту. В Excel храните время **текстом** в формате `HH:MM`. Ночные окна через полночь и несколько дат в одном расчёте не поддерживаются.

Поддерживаемые районы:

`Басманный`, `Таганский`, `Лефортово`, `Нижегородский`, `Текстильщики`, `Рязанский`, `Кузьминки`, `Выхино`, `Южнопортовый`, `Домодедово`, `Зябликово`, `Царицыно`.

Пример JSON:

```json
[
  {
    "id": "DOC-001",
    "bk": "Глобальная проблема",
    "type": "Авария",
    "start": "09:00",
    "end": "11:00",
    "zone": "Басманный",
    "address": "Учебный адрес, 1",
    "skill": "Линия",
    "transport": "Автомобиль",
    "duration": 100,
    "gigabit": "Нет"
  }
]
```

Все импортированные заявки получают `executionStatus: 'planned'` и пустой `actualTime`. Статусы из файла не импортируются; их задают через кнопку «Факт».

### Проверка строк заявок

Отклоняются строки без ID, типа или адреса, с повторным ID среди ранее принятых строк, неизвестным районом, неверным или обратным окном, отсутствующей/неположительной длительностью. Отчёт указывает номер строки и причины. В настройках показываются первые три сообщения, а не полный журнал.

Это проверка основных полей, а не полная схема данных: например, словари навыков и транспорта и конечность чисел проверяются не полностью. Используйте известные значения и конечную положительную длительность в минутах.

## Инженеры

Шаблон: [examples/Инженеры.xlsx](../examples/Инженеры.xlsx).

| Поле | Альтернатива | Правило |
|---|---|---|
| `ID` | `id` | Желательно строковое уникальное значение; при отсутствии создаётся `e1`, `e2` и т. д. |
| `Имя` | `name` или `Инженер` | Обязательно |
| `Навыки` | `skills` | Непустой список через запятую, `;` или `\|` |
| `Транспорт` | `transport` | По умолчанию `Автомобиль` |
| `Начало смены` | `shift_start` | Текст `HH:MM` |
| `Конец смены` | `shift_end` | Текст `HH:MM`, позже начала |
| `Стартовая точка` | — | Описание для карты, может быть пустым |
| `Доступность` | — | `Резерв` включает резерв; текст с `нет` или `недоступ` исключает из доступного состава; остальные значения означают доступность |

Пример строки: ID `e-doc-1`, имя `Учебный инженер`, навыки `Линия, FTTB, Роутер`, транспорт `Автомобиль`, смена `08:00`–`18:00`, доступность `Да`.

Используемые в демо навыки: `Линия`, `FTTB`, `Роутер`, `Подключение`, `TV`, `Гигабит`. Сопоставление навыка нечувствительно к регистру и использует вхождение одной строки в другую. Транспорт сравнивается строго, с учётом регистра: `Автомобиль` и `Общественный транспорт`.

Проверяются имя, непустые навыки и корректная смена. Дубли ID инженеров отдельно не отклоняются, поэтому проверяйте их до загрузки. Числовой ID из Excel не приводится к строке и может нарушить выбор сотрудника в интерфейсе; задавайте ID текстом с буквенным префиксом.

Поле стартовой точки не геокодируется. Координаты импортированного инженера назначаются по порядковому номеру строки. Импорт своих широты и долготы не реализован.

## Длительность и нормативы

В настройках доступен [стандартный XLSX](../dist/assets/Нормативы.xlsx), копия лежит в [examples/Нормативы.xlsx](../examples/Нормативы.xlsx). Его замена через интерфейс не предусмотрена. Расчёт не читает этот файл: значения заданы в JavaScript.

`normFor(type)` выбирает длительность по первому подходящему правилу:

| Подстрока в типе без учёта регистра | Минут |
|---|---:|
| `авари` | 100 |
| `дозаказ` | 40 |
| `локаль`, `линк` или `ремонт` | 50 |
| Остальные типы | 90 |

Явная `Длительность` из файла имеет приоритет. В [requests.csv](../examples/requests.csv) заданы 90, 60, 45, 120 и 90 минут; эти значения используются как есть. Встроенное демо имеет собственные длительности. Поэтому одинаковый тип работы в демо и импортированном файле может дать разное время.

Навык по умолчанию выбирается отдельно: `гбит` → `Гигабит`; `пристав`/`tve` → `TV`; `линк`/`кабел`/`авари` → `Линия`; `роут` → `Роутер`; иначе `Подключение`. Например, «Дозаказ оборудования» без явного навыка получает `Подключение`, хотя в демо есть дозаказ с `FTTB`. Для воспроизводимого расчёта заполняйте навык и длительность явно.

Встроенная таблица нормативов содержит компонент времени дороги, но алгоритм дополнительно прибавляет переезд из матрицы. Перед использованием реальных данных нужно согласовать, включает ли переданная длительность только работу или также дорогу.
