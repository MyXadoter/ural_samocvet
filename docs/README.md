## Термины

- **Заявка** — работа с ID, типом, адресом, районом, навыком, длительностью и временным окном.
- **Маршрут** — упорядоченный список назначений одного инженера со временем работ и переездов.
- **Baseline** — простой алгоритм для сравнения.
- **Regret‑2** — выбор заявки по разнице стоимости второго и первого допустимого варианта назначения.
- **Фиксированная работа** — назначение со статусом «в пути», «начата» или «завершена», сохраняемое при оперативном пересчёте.
- **Дорожная матрица** — таблица времени и расстояний между стартовыми и клиентскими точками.
- **Quality gate** — проверка импортируемых строк с разделением на принятые и отклонённые.

## Соответствие реализации

Источником описания служат [app.js](../dist/app.js), [index.html](../dist/index.html) и поставляемые примеры. Материалы в `materials/` и исходный чек-лист могут описывать желаемое поведение шире текущей реализации. Расхождения перечислены в [ограничениях](VALIDATION.md).

Проект `ural-dispatch` с Python/FastAPI и React — отдельная реализация. Его API, команды сборки, 13 учебных заявок, файловые сессии и тесты не относятся к этому репозиторию.
